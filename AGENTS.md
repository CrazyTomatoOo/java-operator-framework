## Agent skills

### Issue tracker

GitHub issues, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Coding style

Javadoc on all public/protected members, `@param`/`@return`/`@throws` per signature, and grouped import order (android → Huawei → commercial → third-party → net/org → java). See `docs/agents/coding-style.md`.
